## Context

What situation forces a decision? What constraints are in play — technical, financial, regulatory,
temporal? What did we *learn* that made this necessary?

State facts, not preferences. If the context is one sentence, this probably doesn't need an ADR.

invariants (AI-1/2/3), Product Laws, or requirements it satisfies.
